# 升变、位置、攻击与自动回合步骤

- 服务端为每张可用牌列举合法出场格、装备对象和升变对象，并提供实际支付费用；客户端选择后提交，服务端重新校验。
- 手牌统一打开使用弹窗：选择通常/升变/装备、位置和支付费用，保留合法折扣方案。
- 攻击按钮打开目标选择；受攻击方自动收到阻挡/瞬时战术/不阻挡弹窗，不再依赖卡下阻挡标签。
- 在线房间由服务端完成竖直和抽牌，停在抽牌确认；确认后进入费用填充，重连不可重复抽牌。
- 所有玩家可见的属性/卡牌类型标签使用统一中文映射。
- 验证合法选项与实际裁定、升变2费和任意合法位置、攻击角色/玩家、阻挡过滤、自动步骤确认及隐藏信息；双浏览器回归后追加开发记录。
